# Pearedup Website

## Overview
**Pearedup** is a web application that helps users **connect, collaborate, and discover like-minded individuals**. It focuses on a clean and responsive interface to make meaningful connections easy and enjoyable.

---

## Features
- **User Registration & Login** – Secure authentication system.
- **Profile Creation** – Customize personal profiles.
- **Search & Discovery** – Find users with similar interests.
- **Messaging System** – Real-time chat functionality.
- **Responsive Design** – Works on desktop, tablet, and mobile devices.

---

## Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap  
- **Backend:** Node.js / Express (or your chosen backend)  
- **Database:** MongoDB / MySQL (or your chosen database)  
- **Version Control:** Git & GitHub

## Installation

1. Clone the repository:

```bash
git clone https://github.com/yourusername/pearedup.git

Navigate into the project folder:

cd pearedup

Install dependencies:

npm install

Start the server:

npm start

Open your browser and go to:

http://localhost:3000
Usage

Sign up to create an account.

Complete your profile to showcase your interests.

Use the search feature to find users with shared interests.

Connect and start messaging.
